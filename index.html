sauvegarde-marco-tour

Outil de sauvegarde personnel de Marc. Une machine de son foyer envoie chaque nuit une copie chiffrée de ses propres fichiers dans son propre Google Drive, par l'outil libre rclone. Cette application n'a pas d'autre utilisateur et n'est pas proposée au public.

Personal backup tool of its owner: one home machine sends an encrypted copy of the owner's own files to the owner's own Google Drive each night, using the open-source tool rclone. It has no other users and is not offered to the public.
